# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: on this repository, open **Security → Report a vulnerability** ([direct link](https://github.com/elleqt/llm-proxy-backend/security/advisories/new)). Do not open a public issue or pull request for it.

Say what is affected, how to reproduce it, and what an attacker gains. The discussion continues in the private advisory, and the fix is published together with it.

llm-proxy is two repositories. Report here for the gateway, the web API, metrics and the compose files, and in [llm-proxy-frontend](https://github.com/elleqt/llm-proxy-frontend/security/advisories/new) for the web interface and its nginx image. If you are not sure which part is affected, report here.

## Supported versions

Only the latest release receives security fixes. Releases are listed on the [releases page](https://github.com/elleqt/llm-proxy-backend/releases).
